# FHIR Bulk Data Import Operation ($import)

The current draft of a FHIR Bulk Import operation (renamed to Bulk Submit) is at https://hackmd.io/@argonaut/rJoqHZrPle. Ongoing design discussions take place in the Bulk Data stream on https://chat.fhir.org.

This repository contains two very early stage proposals for a FHIR Bulk Data Import Operation that are no longer being maintained.

- [Draft Bulk Data Import - Ping and Pull Proposal](import-pnp.md)
- [Draft Bulk Data Import - Manifest Submission Proposal ](import-manifest.md)
